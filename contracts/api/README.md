# Hợp đồng HTTP API

Khi `backend/api` chạy được, xuất mô tả OpenAPI của FastAPI vào đây để web/Android dùng cùng tên trường, kiểu dữ liệu và mã lỗi. Hiện chưa có API nên chưa có file OpenAPI; không viết đặc tả giả rồi để lệch với triển khai.

Phiên bản đường dẫn đầu là `/api/v1`. Xem các endpoint dự kiến tại [backend/api/README.md](../../backend/api/README.md).
