# Hướng dẫn vận hành

Nơi lưu các quy trình thao tác sau khi hệ thống local/cloud hoạt động: khởi động và dừng dịch vụ, xem log, sao lưu/khôi phục PostgreSQL, xử lý Pi offline, lỗi MQTT và lỗi I²C.

Hiện phần có thể vận hành là code Pi; xem [hướng dẫn Pi](../../health_watch/README.md). Không chạy đồng thời nhiều script cùng giữ GPIO trên Pi.
