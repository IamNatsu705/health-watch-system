# Phần cứng và hiệu chuẩn

Nơi lưu sơ đồ dây, vị trí đeo thử, dữ liệu hiệu chuẩn và biên bản kiểm tra với cảm biến thật. Hướng dẫn nối mạch hiện có ở [README của Pi](../../health_watch/README.md).

Các ảnh `preview_*.png` trong `health_watch/` là ảnh giao diện mẫu, không phải bằng chứng BPM hoặc bước chân đo thật. Nếu thu dữ liệu thực nghiệm, ghi rõ thiết bị, thời điểm, cách gắn cảm biến và phương pháp đối chiếu.
