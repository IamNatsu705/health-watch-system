# Kiểm tra

- `health_watch/tests/`: test logic phần cứng giả lập hiện có, không cần MQTT hay PostgreSQL.
- [`integration/`](integration/README.md): kịch bản kiểm tra đường đi Pi/MQTT/ingest/API sau khi các dịch vụ được triển khai.

Không coi test logic thành xác nhận độ chính xác y tế hoặc xác nhận dây cảm biến ngoài đời.
